# ATS Scoring & Resume Tailoring Engine

Автоматизированная система анализа вакансий и оптимизации резюме под требования ATS (Applicant Tracking System). 

Проект собирает свежие вакансии с HH.ru, оценивает их релевантность профилю кандидата, использует LLM для семантического сопоставления задач и генерирует конкретные рекомендации по адаптации резюме для максимального прохождения автоматических фильтров HR-систем.

## Ключевые возможности

- **Двухэтапный скоринг:** 
  1. *Быстрый детерминированный:* сравнение по словарю навыков и задач (0 запросов к LLM).
  2. *Глубокий LLM-анализ:* семантическое сопоставление формулировок, gap-анализ и предложения по улучшению резюме (топ-N вакансий).
- **Умный бонус за подтверждение:** Навык, упомянутый в списке, дает базовый балл. Тот же навык, подтвержденный реальным описанием в пет-проекте или опыте работы, получает множитель релевантности (×1.3).
- **Экономия токенов:** Продвинутая система кэширования (по хэшу параметров). Повторяющиеся задачи или методы берутся из локального кэша, что позволяет обрабатывать сотни вакансий, тратя API-лимиты только на уникальный контент.
- **Гибкость провайдеров:** Мгновенное переключение между **Yandex Cloud (YandexGPT)** и **OpenRouter** через одну настройку в `config.py`.
- **Детальная отчетность:** Генерация сводного Excel-файла с дельтой скоринга и Markdown-отчета с пошаговым планом адаптации резюме.

## Архитектура пайплайна

1. **Сбор данных (Stage 1-2):** Playwright + BeautifulSoup собирают ссылки и парсят карточки вакансий с обходом базовых анти-бот систем.
2. **Извлечение (Stage 4):** NLP-словарь извлекает из текста структурированные сущности: `tools` (инструменты), `methods` (методы), `tasks` (задачи).
3. **Быстрый скоринг (Step 3):** Вакансии без извлеченных требований отбрасываются. Остальные оцениваются по весовым коэффициентам (Задачи: 50%, Инструменты: 30%, Методы: 20%).
4. **Глубокий LLM-анализ (Step 3 + LLM):** Для ТОП-N вакансий запускается до 5 целевых запросов:
   - Семантика задач (сопоставление разных формулировок одного смысла).
   - Семантика методов.
   - Gap-анализ (поиск критических пробелов).
   - Tailoring suggestions (конкретные формулировки для резюме).
   - Rescore (оценка релевантности после виртуального применения советов).
5. **Отчетность (Step 8):** Сборка итоговых файлов в папке `output/`.

## Стек технологий

- **Язык:** Python 3.10+
- **Сбор данных:** `playwright`, `requests`, `beautifulsoup4`
- **Обработка данных:** `pandas`, `pyyaml`, `re`
- **LLM Интеграция:** Yandex Cloud API (YandexGPT) / OpenRouter API
- **Отчетность:** `openpyxl` (Excel), Markdown

## Установка и настройка

### 1. Клонирование и окружение
```bash
# Создание и активация виртуального окружения
python -m venv .venv
.venv\Scripts\Activate.ps1  # Для Windows PowerShell

# Установка зависимостей
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка API-ключей
Выберите **один** из провайдеров и задайте переменную окружения (рекомендуется сделать это постоянно через `setx`):

**Для Yandex Cloud (Рекомендуется для РФ):**
```powershell
# Единовременно для текущей сессии:
$env:YC_API_KEY="ваш_ключ_начинающийся_на_AQVN"

# Или навсегда для пользователя Windows:
setx YC_API_KEY "ваш_ключ_начинающийся_на_AQVN"
```
*Не забудьте указать ваш `YC_FOLDER_ID` в файле `config.py`.*

**Для OpenRouter (Альтернатива):**
```powershell
$env:OPENROUTER_API_KEY="sk-or-v1-ваш_ключ"
```

### 3. Настройка профиля кандидата
Отредактируйте файл `profile/candidate.yaml`. Укажите ваши реальные навыки, задачи и, что важно, привяжите их к конкретным проектам в разделах `skills_used` и `tasks_done` для активации бонуса за подтверждение.

### 4. Конфигурация
В файле `config.py` вы можете настроить:
- `LLM_PROVIDER`: `"yandex"` или `"openrouter"`
- `TOP_N_VACANCIES`: количество вакансий для глубокого LLM-анализа (по умолчанию 10).
- `MIN_SCORE_THRESHOLD`: минимальный процент совпадения для попадания в отчет (по умолчанию 40).
- `SEARCH_QUERIES`: список запросов для парсинга HH.ru.

## Использование

### Стандартный запуск (с использованием кэша)
Система пропустит уже проанализированные вакансии, сэкономив API-запросы.
```bash
python run_ats.py
```

### Принудительный полный пересчет
Очищает кэш LLM и анализирует ТОП-N вакансий заново (тратит лимиты API).
```bash
python run_ats.py --force
```

## Результаты

После успешного выполнения в папке `output/` будут созданы:

1. **`ats_report_detailed.xlsx`**
   - Лист `Top_Vacancies`: Сводная таблица с базовым скором, скором после LLM, дельтой tailoring, списком совпавших/отсутствующих навыков и конкретными рекомендациями.
   - Лист `Example_Breakdown`: Детальная матрица совпадений по категориям для лучшей вакансии из выборки.
2. **`ats_summary.md`**
   - Человекочитаемый отчет с рейтингом вакансий, выделенными зонами роста (gap analysis) и готовыми формулировками для добавления в резюме.

## Безопасность и лучшие практики

- **Никаких выдумок:** Промпты для LLM жестко инструктируют использовать *только* факты, указанные в `candidate.yaml`.
- **Безопасность ключей:** API-ключи никогда не хардкодятся в репозитории, а считываются из переменных окружения.
- **Устойчивость:** Пайплайн обрабатывает сетевые ошибки, пустые описания вакансий и невалидные JSON-ответы от LLM без падения.
